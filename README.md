# 🐞 AI-Powered Bug Tracking System

An intelligent web-based Bug Tracking System developed using Flask and MongoDB. This application helps teams report, track, manage, and resolve software bugs efficiently while providing AI-powered suggestions for bug analysis.

## 🚀 Features

- User Registration and Login
- Secure Authentication System
- Dashboard for Bug Management
- Create, Update, Delete Bugs
- Assign Bugs to Team Members
- Bug Status Tracking
- Priority Management (Low, Medium, High)
- Search and Filter Bugs
- AI-Based Bug Analysis and Suggestions
- MongoDB Database Integration
- Responsive User Interface
- Cloud-Based Data Storage

## ⚙️ Installation

### 1. Clone Repository

```bash
git clone https://github.com/yourusername/bug-tracking-system.git
```

### 2. Navigate to Project Folder

```bash
cd bug-tracking-system
```

### 3. Create Virtual Environment

```bash
python -m venv venv
```

### 4. Activate Virtual Environment

**Windows**

```bash
venv\Scripts\activate
```

**Linux/Mac**

```bash
source venv/bin/activate
```

### 5. Install Dependencies

```bash
pip install -r requirements.txt
```

### 6. Configure MongoDB Atlas

Add your MongoDB connection string in the configuration file.

### 7. Run Application

```bash
python app.py
```

### 8. Open Browser

```text
http://localhost:5000
```
